# Project Decisions

- Use a simple, professional, and understandable user interface.
- Implement the project through small, phase-by-phase checkpoints.
- Update documentation and diagrams alongside implementation.
- Push to GitHub after verified checkpoints.
- Keep database and container storage separate from older projects.
- Produce an approximately 60-page P1 report based on actual project evidence.
- F1 team onboarding will use one shared team account: all members use one designated login email and one shared password. Member university emails are contact records only, not login identities; there will be no invitations or individual member accounts in this flow. The account creator counts toward the configured group-size limit, which must not be hardcoded.
- Assigned account roles are fixed after authorized account creation. Existing roles cannot be changed through the application; account activation/deactivation remains a separate controlled action.
