# Module 2 source map

Paths are repository-relative and describe only the active implementation.

- Team formation and membership: `backend/app/main.py`, `backend/app/models/team.py`, team-registration schemas, and the team registration/constraint tests.
- Assignment-scoped collaboration: `backend/app/collaboration_channels.py`, `backend/app/models/module2_collaboration.py`, `frontend/src/portals/student/modules/StudentCollaborationChannel.tsx`, supervisor workspace components, and `backend/tests/test_collaboration_channels.py` / `test_collaboration_channel_access.py`.
- Student assistant: `backend/app/group_ai.py`, `backend/app/models/student_ai.py`, `frontend/src/GroupAIChat.tsx`, and `frontend/tests/group-ai-conversations.test.mjs`.
- Project progress: `backend/app/project_workflow.py`, `frontend/src/portals/student/modules/StudentProgressDashboard.tsx`, supervisor project workspace, and `backend/tests/test_project_workflow.py`.

The former compatibility-matching, invitation, join-request, temporary-match-chat and seven named-channel files are retired and intentionally absent from this map.
