# Demonstration evidence

No screenshots or browser results are asserted here. Capture actual evidence only in an isolated test environment, using authorized non-sensitive data. Do not include real student details, credentials, session tokens, secrets or raw roster files.

Suggested capture checklist:

- [ ] Selected cycle and roster eligibility / safe validation outcome.
- [ ] Shared-team registration and successful sign-in.
- [ ] Seven channels, team attribution and assigned Supervisor access boundary.
- [ ] Preferences, opt-in, same-cycle suggestions and withdrawal.
- [ ] Match-chat send, closure, revoked access and fresh mutual consent/new ID.
- [ ] Chatbot unavailable state, or advisory response from an approved configured local runtime.
- [ ] Desktop and mobile layouts, including loading, error and empty states.

For each capture record date, build/commit or worktree state, test environment and steps; mask sensitive information. A screenshot is not proof of backend authorization or transaction integrity.
